# Test Case: Successful Student Login

**Test Case ID:** TC-AUTH-001
**Test Suite:** User Authentication & Access

**Feature:** User Login
**Test Objective:** Verify that a registered student can successfully log in with valid credentials.

---

### Pre-conditions
*   The user must have a registered student account with known credentials (email/password).
*   The application's frontend and backend services must be running.

---

### Test Steps
1.  Navigate to the application's login page.
2.  Enter the student's valid email address in the "Email" field.
3.  Enter the corresponding valid password in the "Password" field.
4.  Click the "Login" button.

---

### Expected Result
*   The user is successfully authenticated.
*   The user is redirected to the student dashboard page.
*   A "Login successful" message is briefly displayed.
*   The dashboard displays the student's name and relevant exam information.
